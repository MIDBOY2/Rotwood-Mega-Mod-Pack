Rotwood Mega Mod Pack 0.1.0-draft6 - SETTINGS GUIDE

Every setting of the loader and of each mod: what it does, its value as shipped, and the file it is in.
Built from the settings files themselves, so it matches this version of the pack.

WHERE THE FILES ARE
Everything is under your Rotwood mods folder:
    %APPDATA%\Klei\Rotwood\steam-<your id>\mods\
Paste %APPDATA%\Klei\Rotwood into the address bar of a File Explorer window to get there.
The paths below start from that mods folder.

HOW TO CHANGE A SETTING
1. Close Rotwood.
2. Open the file in Notepad (right-click, Open with, Notepad).
3. Find the line with the setting name and change what comes after the = sign.
      on / off      true or false
      numbers       0.35, 5, 100 (a dot for decimals, no quotes)
      text          "aim" (keep the quotes)
      lists         { "a", "b" } (keep the braces and commas)
4. Keep the comma at the end of the line. Lines starting with -- are notes and do nothing.
5. Save, then start Rotwood. Settings are read when the game starts.

If the game shows a message about a mod at the main menu after an edit, a comma, quote or brace
went missing in that file. Undo the edit, or copy the original file back from the download
(files\mods\<mod>\scripts\).

YOUR CHANGES AND UPDATES
Running Install again with the same pack version (for example after a game update) leaves your
settings alone. Installing a newer pack version moves the old mod folders, with your settings,
to %APPDATA%\Klei\Rotwood\steam-<your id>\modpack_backup\ and puts fresh ones in: copy your
values over by hand.

SWITCHING A WHOLE MOD OFF
Either put its folder name in disabled_mods in nativeloader_settings.lua (below), or set
"enabled = false" in the mod's own settings file where it has one.

THE LOADER (Native Loader)
File: nativeloader_settings.lua
Native Loader settings (optional file: without it these defaults apply). Data only: no code
runs from here. Lives next to nativeloader.lua in the mods folder.
================================================================================================

enabled = true
    false: load no mods at all (the game runs unmodified)

disabled_mods = {}
    mod folders to leave out, e.g. { "rotwood-stick-aim", "rotwood-perf-probe" }

fast_require = false
    experimental: game scripts are found without first looking in every mod folder

notices = true
    (a mod can then no longer replace a game script by having a file with the same path)
    the message at the main menu when a mod failed to load / the mods are off

verbose = false
    more lines in client_log.txt (every folder looked at, modimport, post-init counts)

Armor Dyes 0.6.0
File: rotwood-armor-dyes\scripts\armordyes_settings.lua
Armor Dyes settings. Restart the game after changing this file.
================================================================================================

enabled = true
    false = the whole mod is off (dyes you picked stay in the save and come back when it's
    on again)

dye_tab = true
    the ARMOUR DYE tab in the character screen (the mirror in town)

weapon_dyes = true
    a WEAPON sub-tab in ARMOUR DYE: dye the weapon you're carrying. (0.5.6) Every dye is
    worked out from that weapon's own colours like armour's (its colours turned, not
    painted over): the colour families, the neutrals, the 21 colour dyes, the 4 soft
    player colours and your own dyes. Every weapon keeps its own dye. false = no weapon
    tab, weapons in their normal colours.

dye_weapon_trails = true
    (0.5.9) The spear's twirl trail (drawn in the spear's own colours) takes the spear's
    dye too. false = the trail in its normal colours (0.5.8 and before).

palettes = true
    (0.5.6) Tint palettes: a whole colour scheme per piece instead of one colour (each
    material its own palette colour: main, second, accent, metal...), the boss looks'
    palettes and colour palettes. Live colour shifts, no extra art.

palette_tab = true
    a PALETTES sub-tab in ARMOUR DYE: one click puts a palette on the helmet, body, legs
    and weapon together

palettes_in_lists = false
    the palettes in each piece's own list too (HELMET / BODY / LEGS / WEAPON), to mix
    palettes per piece. Longer lists. false = PALETTES tab only.

custom_dyes = { ... }
    Dyes of your own, added after the built-in ones. These are a plain colour shift, the
    same on every armour set (not colour-matched): hue        = degrees to turn the
    colours (0-360) saturation = colour strength x (1 = unchanged, 0 = grey) brightness =
    x (1 = unchanged, 0.6 = darker, 1.2 = lighter)

new_character_colour = true
    A brand-new character (made on the new-character screen) starts with its basic armour
    in its player's soft colour: player 1 Soft Blue, player 2 Soft Yellow, player 3 Soft
    Teal, player 4 Soft Purple. Only once, only basic armour it hasn't dyed; change it at
    the mirror any time. false = new characters start in the original colours.

loadout_dyes = "auto"
    Loadouts remember the dye on each piece they wear (a Morphic piece: the dye on the
    boss look it shows), and equipping a loadout puts them back. "auto" = a dye you pick
    while wearing a loadout goes into it straight away (and its loadout statue changes
    with it) "save" = like gems: a changed dye marks the loadout as changed; save the
    loadout to keep it, switching loadouts puts its own dyes back false  = dyes aren't
    part of loadouts (as before) Loadouts saved before this don't change your dyes until
    they have some.

statue_look = true
    The loadout statue in town shows the loadout as you'd wear it: the boss look of
    Morphic armour (its gem), mirage looks, and the dyes. false = the game's statue (plain
    pieces, no dyes).

imbued = true
    (0.5.0) The imbued boss looks: the seven bosses' armour and weapons in their imbued
    (elite) colours. Each boss look gets "Imbued" first in its ARMOUR DYE list (helmet,
    body, legs, and its weapons in WEAPON), and the mirage station gets imbued patterns.
    The art loads in town (for the previews) and in a hunt only for the imbued pieces your
    hunters wear. false = none of it.

imbued_alt_looks = true
    The extra imbued looks after "Imbued": Treek Plum, Eggzy First and Salmon, Grimhollow
    Lava and Lava with the magenta glow. false = only "Imbued" (less art loaded in town).

imbued_reference_looks = false
    (0.5.9) Reference looks: older versions kept to compare with. Right now Grimhollow's
    lava bow with its first, red / pink string ("Imbued: Lava, red bow string" and
    "Imbued: Lava, magenta glow, red bow string"; the lava bow's string is now orange).
    false = left out (no art loaded for them).

imbued_mirage = true
    Imbued patterns at the mirage station (for any item of that slot; weapons of that
    weapon type), at the usual price. false = the dyes only.

imbued_icons = true
    A piece in an imbued look shows the imbued icon (inventory, mirage station, loadouts).
    false = the normal icons.

imbued_needs_boss_piece = true
    The imbued patterns of a boss piece come with owning it (its weapon, its armour look,
    or a Morphic piece showing it). false = all imbued patterns from the start.

debug = false
    extra lines in client_log.txt
